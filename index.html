What is yieldboard?

yieldboard is a free, open-source desktop application built for Windows that helps you keep an eye on your cryptocurrency earnings without needing to navigate complex DeFi dashboards or spreadsheets. Whether you are staking tokens on Ethereum, providing liquidity on Arbitrum, or lending on Solana, yieldboard brings your numbers together in a clean, easy-to-read interface.

It is designed for everyday users who want to understand how their crypto investments are performing. You do not need any programming knowledge to use it. Just download the app, run it on your Windows computer, and start tracking. yieldboard respects your privacy — your data stays on your machine, and the app does not require you to connect a wallet or share private keys.

Built with C++ and native Windows APIs, yieldboard is lightweight, fast, and does not require a browser or an internet connection for basic portfolio viewing (though live data updates need an internet connection). It supports multiple chains including Ethereum, Arbitrum, and Solana, making it a versatile companion for anyone active in decentralized finance.

🖱️ How to Use yieldboard

Once you have installed and launched yieldboard, you will be greeted with a clean, intuitive interface. Here is a quick walkthrough to help you get started:

  1. Add your first position: Click the "Add Position" button and choose the blockchain network (Ethereum, Arbitrum, or Solana). Enter the token name, the amount you have staked or supplied, and the current yield rate (APY).
  2. View your dashboard: Your positions will appear on the main dashboard, showing your estimated daily, monthly, and yearly earnings.
  3. Update rates: Click the "Refresh" button to fetch the latest APY and token prices from public data sources. This requires an internet connection.
  4. Organize your portfolio: You can group positions by protocol or chain, and sort them by yield or value. The app saves your data locally, so it will be there the next time you open it.
  5. Export your data: Use the export function to save a CSV file of your portfolio for your own records or for tax purposes.

There is no need to connect a crypto wallet or create an account. yieldboard is a standalone tracker that puts you in control.

🔧 Troubleshooting

If you encounter any issues while using yieldboard, here are some common solutions:

  • The app does not start: Make sure you have downloaded the correct version for Windows. Try running the application as administrator by right-clicking the file and selecting "Run as administrator".
  • Data does not refresh: Check your internet connection. Some networks block certain API endpoints; try switching to a different network or using a VPN.
  • Windows SmartScreen warning: Because yieldboard is open-source and not signed by a large publisher, Windows may show a warning. Click "More info" and then "Run anyway" to proceed. You can verify the file integrity on the releases page.
  • Missing .dll errors: Ensure that you have the latest Microsoft Visual C++ Redistributable installed. You can download it for free from Microsoft's website.
  • App runs slowly: Close other background applications to free up memory. If you have a very large number of positions, consider exporting and archiving older ones.

For more help, visit the GitHub repository and open an issue. The community and maintainers are happy to assist.

Do I need to connect my wallet?
No. yieldboard is a manual tracker. You enter your positions yourself, which means you never share private keys or grant any permissions to the app.

Which blockchains are supported?
The app is designed to track yields on Ethereum, Arbitrum, and Solana, as indicated by its topic tags. Support for additional chains may be added in future updates.

Can I use yieldboard on Mac or Linux?
yieldboard is built as a Windows desktop application using native Windows APIs. The official releases are for Windows only. However, since it is open-source, you may find community builds or compile it yourself.

How do I update the app?
Simply visit the releases page again and download the latest version. Your local data will remain intact as long as you do not delete the data folder.

Where is my data stored?
All data is stored locally on your computer in the application's data directory. No information is sent to external servers except for public API calls to fetch yield rates.
